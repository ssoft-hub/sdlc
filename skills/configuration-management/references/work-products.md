# Work products of configuration management

"This process" as a source or a receiver is a task of configuration management passing the work
product to a later one. The suppliers are the links of the supply chain the configuration
management requirements pass to; the acquirer is the other party to the agreement; the
stakeholders are those the items and their status are made available to.

## Inputs

| Work product | Outcomes it serves | Source |
|---|---|---|
| the configuration management plan in force | items managed, requirements distributed | this process |
| the release plan | items managed, releases approved | the project planning process, for the dates of delivery; the maintenance process, for the maintenance releases |
| the handling and storage guide | items managed, releases approved | this process, for the guide in force; the infrastructure management process, for storage and backup |
| the product configuration | items managed | the architecture definition process: the elements and their place in the architecture |
| the configuration item | items managed, baselines established, changes managed, status maintained, audits performed, releases approved | the business or mission analysis process; the stakeholder needs and requirements definition process; the system/software requirements definition process; the architecture definition process; the design definition process; the system analysis process; the implementation process; the integration process; the verification process; the validation process; the supply process |
| the product: accepted | items managed | the acquisition process |
| the acceptance record | items managed, status maintained, releases approved | the acquisition process, for the product accepted; the transition process; the operation process; the maintenance process; the disposal process |
| the hardware resources register, the software assets register | items managed | the infrastructure management process |
| the verification strategy, the validation strategy, the transition strategy: items for a baseline | items managed, baselines established | the verification process; the validation process; the transition process |
| the verification results | baselines established, changes managed | the verification process, for the baseline |

| the tracking system | changes managed, status maintained | the infrastructure management process |
| the configuration management library | changes managed, status maintained, releases approved | the infrastructure management process, for the tool |
| the change history | changes managed, status maintained | the maintenance process; the disposal process |
