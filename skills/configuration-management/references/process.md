# The configuration management process

| Name | Statement | Observable as |
|---|---|---|
| purpose | the system elements and the configurations are managed and controlled over the life cycle, the product is kept consistent with the definition of its configuration, and the integrity of the identified outputs of the project - for software, of the software items - is established, maintained and made available to the stakeholders | - |
| items managed | the configuration management strategy is defined, and the items that require configuration management are defined and managed | the strategy and the plan recorded, or the rules of the version control system serving as them; each item identified, with its description current |
| baselines established | the baselines of the configuration are established | each baseline recorded with the items and the versions it holds and the decision that established it |
| changes managed | the changes to the items under configuration management are managed | each change request recorded with its evaluation and its decision, and each change tracked to closure with its reason and its authority |
| status maintained | the configuration status information is maintained and made available throughout the life cycle | the status records and reports, the history of each item, the changes and the releases available to the stakeholders |
| audits performed | the required configuration audits are performed, and the completeness and the consistency of the items are ensured | the record of each audit or supervision with its results and the dispositions on the items |
| releases approved | the releases and the deliveries are managed and approved, and the storage, handling and delivery of the items are controlled | the release approval record with the release criteria checked; the delivery record; the master copies kept |
| requirements distributed | the configuration management requirements are distributed along the supply chain | the requirements passed to each supplier working under an agreement with the project whose elements are part of the system |
