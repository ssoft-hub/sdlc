# Work products of risk management

"This process" as a source or a receiver is a task of risk management passing the work product to a
later one.

## Inputs

| Work product | Outcomes it serves | Source |
|---|---|---|
| the project plan | risks identified | the project planning process |
| the risk management plan | every outcome | this process, for the plan in force; the project planning process, for what the project plan sets on risks; the portfolio management process, for the risks of the portfolio |
| the supplier evaluation report | risks identified | the acquisition process |
| the risk analysis report | risks identified, risks analysed, risk state measured | the supply process; the operation process, for the operation risks |
| the risk category report | risks identified, risks analysed, risk state measured | the operation process, for the operation risks |
| the risk action request: the decisions on earlier requests | risks identified, risks analysed, responses selected, responses implemented | this process |
| the risk mitigation plan in force | risks identified, risks analysed, responses selected, responses implemented | this process |
| the tracking system | every outcome | the infrastructure management process |

## Outputs

| Work product | Outcomes it serves | Receiver |
|---|---|---|
| the risk management plan | every outcome | the project planning process; the portfolio management process; the acquisition process; the supply process; the project assessment and control process, for the management review |
| the risk analysis report | risks identified, risks analysed, risk state measured | the supply process |
| the risk category report: the risk profile | risks identified, risks analysed, risk state measured | the stakeholders |
| the risk measure | risk state measured | the measurement process; the operation process, for the analysis of operation risks |
| the risk action request | risks identified, risks analysed, responses selected, responses implemented | the stakeholders who decide on risks, for the decision on the response |
| the risk mitigation plan | risks identified, risks analysed, responses selected, responses implemented | the project planning process; the project assessment and control process |
| the recovery plan | risks analysed, responses selected, responses implemented | the operation process; the maintenance process |
| the corrective action register | responses selected, responses implemented | the project assessment and control process |
| the tracking system | every outcome | the project assessment and control process |
