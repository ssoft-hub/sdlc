# Assets in use

The domain models and architectures are those of `references/domain-engineering.md`.

## Acts of this situation

| Act | An explicit request does not decide it while | Tasks still due on an explicit request |
|---|---|---|
| changing an asset that others use | the change affects a system or a product that uses the asset | Options, Notification |
| retiring an asset | - | Retirement, Notification |

## Managing knowledge, skills and knowledge assets

Outcomes served: taxonomy defined, knowledge developed, knowledge available, use analysed.

| Subject | What the agent does |
|---|---|
| Requests of users | shall pass the modification requests and problem reports of an asset's users to the domain engineer, for analysis and for adjusting plans and actions |
| Their tracking | shall register and track each such request and report through to the action that follows |
| Change requests for assets | shall analyse and track them in the change control record, and make the changes needed |
| Change requests for domain models | shall analyse and track those for domain models and domain architectures in the change control record, and make the changes needed |
| Options | shall consider, in analysing a modification request for an asset and selecting an option, the conformance to the domain models and architecture, where the project has them, the impact on the systems and products using the asset and on its future users, and its reusability |
| The change | shall have each changed part of an asset - a requirement, the architecture, the design, a system element - changed by the process that changes it in any product: system/software requirements definition, architecture definition, design definition or implementation, then integration and verification |
| Support | may support an asset by the work of maintenance and of problem resolution, which quality assurance carries |
| Retirement | shall retire an asset from the asset repository and the retrieval mechanism by the procedures and criteria for ending its use and by the asset management strategy |
| Notification | shall notify all users of an asset and the domain engineer of each problem found in it, each modification, each new version and its removal, with its configuration status report |
| Use | shall monitor the use of knowledge, skills and assets and record it in the asset use data |
| Each reuse | shall track each reuse of an asset - record it, gather feedback on the actual use - and report it to the domain engineer |
| Analysis | shall analyse the usage data gathered |
| Value | shall periodically reassess the technological and market value of the knowledge assets |
