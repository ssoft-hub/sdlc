# Planning the infrastructure

## Establishing the infrastructure

Outcomes served: requirements defined, elements specified, elements obtained, elements
implemented.

| Step | What the agent does |
|---|---|
| Context | should consider the needs in the context of the organization's other projects and resources, its policy and its plans |
| Constraints | should evaluate the business constraints and the dates that bear on the project |
| Factors | should take into account the project's plans and future needs, physical factors, logistics and human factors, health and safety included |
| Definition | should define and record the infrastructure so that it meets the requirements of the process that uses it, with regard to the appropriate procedures, standards, tools and techniques |
| Configuration management library | shall obtain and put into service, as infrastructure elements, the configuration management library that the configuration management process works with: its tool and its storage |
| Plan | should plan and record the creation of the infrastructure and its configuration, with regard to functionality, performance, safety, security, availability, space requirements, equipment, costs and time constraints, as the development environment plan and the logistics support plan |
| Backup | should provide, as an infrastructure service, the backup and recovery the project's processes require, those of configuration items included, backing up and recovering what the configuration management process determines |
| Backup record | shall record each backup and each recovery made, where backup is provided |
| Storage | should record, where backup is provided, the storage locations, conditions and media of what is backed up, in the handling and storage guide |
