# Maintaining the infrastructure

## Maintaining the infrastructure

Outcomes served: infrastructure maintained.

| Step | What the agent does |
|---|---|
| Evaluation | shall evaluate to what degree the infrastructure provided meets the project's requirements |
| Monitoring | shall monitor the infrastructure so that it continues to meet the requirements of the process that uses it |
| Changes | shall identify and provide improvements or changes to the infrastructure as the project's requirements change, those that the technical processes name for their enabling systems included, by the steps of the core table of `SKILL.md`, and a withdrawal by those that the acts table of `SKILL.md` names for it |
| Servicing | shall service the infrastructure - correct its defects, improve its efficiency - so that it remains stable and reliable |
| Corrective actions | shall register each corrective action taken on the infrastructure in the corrective action register |
| Improvement procedure | may apply the organization's process improvement procedure to improve an infrastructure element |
