# Work products of infrastructure management

The outcomes are those `references/process.md` names. Where this process is the source, the work
product is the version in force that the process updates.

## Inputs

| Work product | Outcomes it serves | Source |
|---|---|---|
| the infrastructure requirements | requirements defined, elements specified | the project planning process; the business or mission analysis, stakeholder needs and requirements definition, system/software requirements definition, architecture definition, design definition, system analysis, implementation, integration, verification, transition, validation, operation, maintenance, disposal and measurement processes, for the requirements for their enabling systems; this process, for the requirements in force |
| the process description | requirements defined, infrastructure maintained | the life cycle model management process |
| the development environment plan | elements specified, elements obtained, elements implemented | the project planning process |
| the logistics support plan | elements specified, elements obtained | the project planning process |
| the acquisition plan | elements obtained | the acquisition process; the project planning process, for the acquisition of the materials and services of enabling systems |
| the supplier selection policy | elements obtained | the acquisition process |
| the hardware resources register, the software assets register | elements specified, elements implemented | this process; the knowledge management process, for the registered assets |
| the tracking system | elements obtained, elements implemented | this process |
| the delivery record | elements implemented, infrastructure maintained | the supplier of the infrastructure element |

## Outputs

| Work product | Outcomes it serves | Receiver |
|---|---|---|
| the infrastructure requirements | requirements defined, elements specified | the acquisition process, for an element acquired; the project planning process |
| the development environment plan | elements specified, elements obtained, elements implemented | the project planning process |
| the logistics support plan | elements specified, elements obtained | this process, for obtaining the resources |
| the hardware resources register, the software assets register | elements specified, elements implemented | the configuration management process; the knowledge management process |
| the tracking system | elements obtained, elements implemented | the acquisition, supply, project assessment and control, risk management, configuration management, quality assurance, verification, validation and operation processes, which keep records in it |
| the delivery record | elements implemented, infrastructure maintained | every process that uses the element |
| the backup / recovery record | elements implemented, infrastructure maintained | the information management process |
| the corrective action register | infrastructure maintained | the quality assurance process |
| the handling and storage guide: storage locations, conditions and media, backup | elements implemented, infrastructure maintained | the configuration management process |
| the configuration management library: the tool and the repository | elements obtained, elements implemented | the configuration management process |
