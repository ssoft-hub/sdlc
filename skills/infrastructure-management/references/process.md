# The infrastructure management process

| Name | Statement | Observable as |
|---|---|---|
| purpose | infrastructure and services are provided to projects to support the goals of the organization and of the projects throughout the life cycle: the facilities, the tools, the communications and the information technology assets the work needs | - |
| requirements defined | the infrastructure requirements are defined | the infrastructure requirements recorded: the processes the infrastructure supports, and the procedures, standards, environments, tools and techniques it needs to support them |
| elements specified | the infrastructure elements are identified and specified | each element named with its specification and its planned configuration |
| elements obtained | the infrastructure elements are developed or acquired | each element developed by the project or accepted from its supplier, meeting the requirements |
| elements implemented | the infrastructure elements are implemented | the elements integrated into an environment and put into service by the time the process that uses them starts |
| infrastructure maintained | the infrastructure is managed, maintained and improved | the evaluation of the infrastructure against the requirements, its defects corrected, and the changes provided as the requirements change |
