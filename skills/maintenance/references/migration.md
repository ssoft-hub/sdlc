# Migration

## Acts of this situation

| Act | An explicit request does not decide it while | Tasks still due on an explicit request |
|---|---|---|
| migrating the software or its operational data to a new environment, the migration plan included | an impact that the request does not name (an incompatible interface change, a data conversion without a way back) | Analysis of `SKILL.md`; Migration plan; Notification |
| ending the support of the old environment | - | Notification |
| ending the parallel operation of the old and the new | the release has not passed the acceptance test the agreement requires | Parallel operation; Notification |

Ending the support of a software product is an act of the disposal process.

## Performing maintenance

Outcomes served: elements available, needs reported.

| Step | What the agent does |
|---|---|
| Products of a migration | shall produce each product and all data produced or modified during a migration to a new operational environment by the software life cycle processes |
| Migration plan | shall develop, record and carry out a migration plan, the users taking part, covering the analysis of the requirements and the definition of the migration, the migration tools, the conversion of the product and the data, the execution and the verification of the migration, and the support of the old environment in the future |
| Notification | shall notify the users and all concerned of the migration plans and activities: why the old environment is no longer supported, a description of the new environment with the date it becomes available, and the other support options once the support of the old environment ends, recording each notification |
| Parallel operation | may run the old and the new environment in parallel for a smooth transition |
| Training | shall provide the training the contract requires during the parallel operation |
| Migration done | shall notify all concerned once the scheduled migration is carried out, recording each notification |
| Archive | shall place the documentation, the logs and the code of the old environment in archives |
| Later review | shall review, after a period of observing the operation, the impact of the changes on the new environment |
| Its results | shall send the results of that review to the appropriate authorities for information, guidance and action |
| Old data | shall keep the data used by the old environment or associated with it accessible as the contract requires for data protection and audit |
