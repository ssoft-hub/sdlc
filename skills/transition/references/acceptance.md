# Delivery and acceptance

The acquirer is the other party to the agreement, to which the product is delivered, at which it is
installed and which conducts its acceptance; it is not a process.

## Acts of this situation

| Act | An explicit request does not decide it while | Tasks still due on an explicit request |
|---|---|---|
| leaving an acceptance problem unresolved | - | Acceptance problems |

## Performing transition

Outcomes served: installed and capable, ready for operation.

| Subject | What the agent does |
|---|---|
| Delivery | shall pack the product for its delivery as the agreement defines |
| Who installs | shall install the release itself, or assist the acquirer in installing it, as the agreement defines |
| Installation guide | shall supply the installation guide by which the acquirer, the operation or the maintenance process installs the release, where the project does not install it itself |
| Acquirer's installation | may leave the installation to the acquirer, by that installation guide |
| Installation tests | should demonstrate the installation by the acceptance tests the supply agreement defines, with special attention to the connections with the environment and the other systems, on a representative example as `references/site.md` sets where the exact environment is not available |
| Capability criteria | should take from the agreements' acceptance tests the criteria for demonstrating the capability to perform the required functions and services after installation and staffing with operators |
| Acceptance test plan | shall agree with the acquirer the acceptance test plan the acceptance tests follow, taking the acquirer's plan where the acquirer supplies one |
| Acceptance support | shall support the reviews and the acceptance tests the acquirer conducts, which take into account the results of the reviews, the audits and the qualification testing of the software and of the system, where performed, and record their results |
| Acceptance record | shall record the acceptance: what the acquirer accepted, when and by what decision |
| Supply duties | should perform by the steps of `SKILL.md` the installation duties the supply agreement carries |
| Putting into use | should put the product into use as intended in the customer's environment itself, where the agreement requires it |

## Managing transition results

Outcomes served: ready for operation.

| Subject | What the agent does |
|---|---|
| Acceptance problems | shall identify the problems found in delivery and acceptance, report them to those responsible for resolving them, and have them resolved by agreement, unless a decision leaves one unresolved |
