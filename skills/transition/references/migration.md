# Operational data migrated or a system replaced

## Acts of this situation

| Act | An explicit request does not decide it while | Tasks still due on an explicit request |
|---|---|---|
| migration or conversion of operational data | there is no backup or way of reverting; the data migration is irreversible | Migration; Way back of `SKILL.md` |
| ending the parallel operation of the system being replaced | the release has not passed the acceptance test the agreement requires | Parallel operation |

Migrating the software to a new environment is an act of the maintenance process.

## Performing transition

Outcomes served: installed and capable.

| Subject | What the agent does |
|---|---|
| Migration | should account in the installation for the migration of the data it requires |
| Parallel operation | shall support the parallel activities the agreement requires where the release replaces an existing system - a system retired by its disposal included -: the product evaluated in its environment in parallel with the existing systems or processes until it passes the acceptance test |
