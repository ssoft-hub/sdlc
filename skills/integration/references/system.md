# A software item or the system integrated whole

## Performing integration

Outcomes served: system integrated, internal interfaces checked, external interfaces checked.

| Subject | What the agent does |
|---|---|
| System | shall combine the software items, where necessary, with hardware, manual operations and other systems into a system |
| Complete system | shall build from all the elements, under the strategy, a complete system ready for system testing, demonstrating conformance to the system design and the complete set of usable deliverable elements |
| Qualification tests | shall develop and record, for each qualification requirement of the system and of the software item, a set of tests, test cases - inputs, expected results, criteria - and procedures for qualification testing, so that the integrated system and the software item are ready for it |
| Transmittal | shall pass the integrated system and the software item to the verification process with a test item transmittal report |
| Evaluation of the system | shall evaluate the integrated system for how far the tests cover the system requirements, applicability of the test methods and standards, conformance to the expected results, and feasibility of qualification testing, of operation and of maintenance, and record the results |
| Evaluation of the item | shall evaluate the integration plan, the design, the code, the tests, the results and the user documentation of the software item for traceability to and external consistency with the system requirements, internal consistency, how far the tests cover the requirements for the software item, appropriateness of the test methods and standards, conformance to the expected results, and feasibility of qualification testing, of operation and of maintenance, and record the results |
| Its criteria | should include in the evaluation criteria the consistency and traceability between the software design and the software items |
| Reviews | shall have the integrated software item and the results of its evaluation pass a technical review, which the verification process conducts, and a management review, which the project assessment and control process conducts |

## Managing integration results

Outcomes served: anomalies recorded.

| Subject | What the agent does |
|---|---|
| Divergence | should take corrective actions, or have the requirements changed by "Defect" of `references/problems.md`, where the system's interaction with the operational environment and the systems enabling its use diverges from the requirements |
