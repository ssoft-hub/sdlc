# The integration process

| Name | Statement | Observable as |
|---|---|---|
| purpose | a system that satisfies the system requirements, the architecture and the design is created from the implemented system elements - for software, units and components are combined into software items consistent with the design, which demonstrate on the operational platform or its equivalent that the software requirements are satisfied; the interfaces are identified and integrated for the interoperation of the elements, and the enabling systems are integrated with the system of interest | - |
| constraints identified | the integration constraints that influence the requirements, the architecture or the design are identified | the constraints recorded and passed to the system/software requirements definition, architecture definition and design definition processes; a defect of an accepted output recorded with its change request |
| approach defined | an approach and checkpoints for the correct operation of the assembled interfaces and functions are defined | the checkpoints, the integration strategy, the integration plan and the regression strategy recorded, and the tests of each element described |
| enabling inputs identified | the inputs for the requirements for the enabling systems or system elements that enable integration are identified | the enabling systems planned and the inputs for their requirements identified |
| enabling systems available | the enabling systems or services integration needs are available | access obtained to each enabling system planned |
| system integrated | a system is integrated from the implemented elements | the assembled configuration under its baseline, traced to the design, with the integration results recorded |
| internal interfaces checked | the interfaces between the implemented elements are checked | the recorded results of the tests of the interfaces between the elements, the regression tests included |
| external interfaces checked | the interfaces between the system and the external environment are checked | the recorded results of the tests of the external interfaces on the operational platform or its equivalent |
| anomalies recorded | the anomalies that appeared during integration are recorded | each anomaly recorded with its source |
