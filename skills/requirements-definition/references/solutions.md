# Feasibility and alternative solutions

## Analysing system requirements

Outcomes served: requirements analysed.

| Subject | What the agent does |
|---|---|
| Feasibility | shall consider the feasibility of the solution by suitable techniques |
| Alternatives | shall consider and analyse alternative solutions and optimize the preferred one |
| Techniques | may use feasibility analysis, case studies, prototyping, formal languages and workshops among the techniques of solution analysis |
| Question | should state to the system analysis process the analysis question: the problem, the goals, the fidelity required |
| Support of the analysis | should have the system analysis process evaluate feasibility, affordability and balance |

A choice between solutions that binds the project is an act of the decision management process.
