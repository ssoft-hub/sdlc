# Work products of architecture definition

The outcomes are those `references/process.md` names. The stakeholders are the individuals and organizations
with an interest in the system, who formally agree to the architecture and to whom it is
communicated. The processes that work to the architecture receive it as the system architectural
design, the system element, the high level software design, the software item and the database
design.
