# Keeping the results of system analysis

## Performing system analysis

Outcomes served: results provided.

| Subject | What the agent does |
|---|---|
| Earlier studies | should keep the results consistent with the studies completed earlier and name a divergence from them |

## Managing system analysis

Outcomes served: results provided.

| Subject | What the agent does |
|---|---|
| Extent of traceability | should keep the traceability of the results bidirectional throughout the life cycle, between the results and each item of the system for which the analysis supports a decision or gives a rationale - a value of a requirement, an architecture alternative -, in the place the project keeps them |
| Configuration | should take the analysis results and reports as candidates for the baseline, which configuration management establishes and maintains |
