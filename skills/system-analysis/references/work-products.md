# Work products of system analysis

The outcomes are those `references/process.md` names. "This process" as a source is a task of system
analysis passing the work product to a later one. The stakeholders of the analysis are those the
step "Stakeholders" of `SKILL.md` identifies; the object of the analysis - a requirement, an
architecture, a design - comes with the analysis question from the process that poses it.

## Inputs

| Work product | Outcomes it serves | Source |
|---|---|---|
| the analysis question: the problem, the goals, the fidelity required | studies identified | the business or mission analysis process; the stakeholder needs and requirements definition process; the system/software requirements definition process; the architecture definition process; the design definition process; the portfolio management process; the decision management process |
| the alternative solution | results provided | the business or mission analysis process; the architecture definition process; the design definition process |
| the data and models for analysis | results provided | this process, for the data on the object the question names; the measurement process |
| the assumptions of the analysis | assumptions agreed | the stakeholders of the analysis |

## Outputs

| Work product | Outcomes it serves | Receiver |
|---|---|---|
| the alternative solution, evaluated | results provided | the decision management process |
| the infrastructure requirements, for the enabling systems of the process | inputs identified | the infrastructure management process |
| the assumptions of the analysis, agreed | assumptions agreed | the stakeholders of the analysis |
| the analysis report | assumptions agreed, results provided | the decision management process; the business or mission analysis process; the stakeholder needs and requirements definition process; the system/software requirements definition process; the architecture definition process; the design definition process; the portfolio management process |
| the traceability record | results provided | the quality assurance process |
| the configuration item: the analysis results in the baseline | results provided | the configuration management process |
