# An element packaged, stored or delivered

## Performing implementation

Outcomes served: element implemented, element packaged or stored.

| Subject | What the agent does |
|---|---|
| Content of the user documentation | should include in the user documentation the preliminary versions of the installation, operation and servicing documentation |
| Evidence | should make the evidence conform to the agreement, the legislation and the organization's policy, include in it the results of testing, analyses, inspections, demonstrations and the other verification activities and the changes of the element made for the changes or nonconformities verification and validation found, and make it part of the element, its implemented baseline |
| Criteria by kind | should have a software element verified for conformance to the system requirements and the design criteria, a service element to the service delivery criteria, and an operational resource - a procedure, user training - to the system requirements and the operational concept |
| Deliverable product | shall keep the operation and maintenance of the deliverable product after its delivery independent of the non-deliverable items used in its development: the tools, scripts, environments and test stubs |
| Non-deliverable items | may use non-deliverable items in development and maintenance |
| Dependence | should treat a non-deliverable item the deliverable product depends on nonetheless as deliverable |
| Packaging | shall have the system element packaged and stored, and the software item packaged and kept with its build list under the agreement on its delivery |
| Storage | should keep the element so that its characteristics are preserved during transport and storage, and have configuration management and information management keep the final configuration and the product information of an element placed in storage |

## Managing implementation results

Outcomes served: element packaged or stored.

| Subject | What the agent does |
|---|---|
| Baselines | shall maintain the key information items selected for baselines, making the baselines and the combining of configuration items at the dates the acquirer and the supplier have determined |
| Supporting processes | shall perform the supporting processes to the extent the agreement requires |

The baselines and the configuration items, the implemented elements among them, are established and
maintained by the configuration management process.
