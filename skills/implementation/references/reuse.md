# An element acquired, reused or adapted

## Preparing for implementation

Outcomes served: element implemented.

| Subject | What the agent does |
|---|---|
| Reuse | should determine, for an element reused, the level of reuse, its source and its suitability |
| Proposal | should propose an implemented element fit for reuse to the knowledge management process, as a reusable object with its reuse proposal |

## Performing implementation

Outcomes served: element implemented.

| Subject | What the agent does |
|---|---|
| Acquisition or adaptation | shall acquire a software element, or adapt a reused or modified one, under the step "Procedures" of `SKILL.md` |
| Adaptation | should carry out the adaptation of a reused or modified element as its configuration |
