# Work products of business or mission analysis

The outcomes are those `references/process.md` names. Organization management is a role within the
organization that sets its strategy, neither a process nor a party outside the life cycle.

## Inputs

| Work product | Outcomes it serves | Source |
|---|---|---|
| the organization's strategy: its concept of operations, strategic goals and plans | problem space defined, class selected | organization management |
| the business goals | problem space defined, classes analysed | the portfolio management process |
| the analysis report: the values of the criteria for each class | classes analysed | the system analysis process |
| the selected solution class: the decision record | class selected | the decision management process |

## Outputs

| Work product | Outcomes it serves | Receiver |
|---|---|---|
| the organization's strategy: the feedback on the selection | class selected | organization management |
| the market analysis report | problem space defined | the supply process; the acquisition process; the portfolio management process |
| the problem and opportunity space | problem space defined | the portfolio management process |
| the life cycle concepts: the operational concept and the others | concepts defined | the architecture definition process |
| the alternative solution: the alternative solution classes | classes analysed | the system analysis process; the decision management process |
| the analysis question: the problem, the goals, the fidelity required | classes analysed | the system analysis process |
| the analysis report: the evaluation of the alternative classes | classes analysed | the decision management process; the portfolio management process |
| the selected solution class: the decision record | class selected | the portfolio management process; the architecture definition process; the acquisition process; the supply process |
| the preliminary life cycle concepts, the problem and opportunity space and the selected solution class, in one transfer | problem space defined, concepts defined, class selected | the stakeholder needs and requirements definition process |
| the traceability record | traceability established | the stakeholder needs and requirements definition process; the quality assurance process |
| the infrastructure requirements: for the enabling systems of the analysis | enabling systems available | the infrastructure management process |
| the configuration item: the items of the analysis in a baseline | problem space defined, solution space characterized, concepts defined, classes analysed, class selected | the configuration management process |
