# The classes analysed in depth

## Characterizing the solution space

Outcomes served: classes analysed.

The agent should apply the architecture definition process where the user's architecture viewpoint
on the solution space is needed.

## Evaluating alternative classes

Outcomes served: classes analysed, class selected.

| Subject | What the agent does |
|---|---|
| Question | should state to the system analysis process the analysis question: the problem, the goals, the fidelity required |
| Values | should obtain the value of each criterion for each class from the system analysis process, structure the affordability trade-offs, cost included, and understand the risks, the feasibility and the value of each class through models, simulation, analytical methods or expert evaluation |
| Conduct | should conduct the selection through the decision management process |
