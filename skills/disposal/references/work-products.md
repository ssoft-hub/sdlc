# Work products of disposal

The outcomes are those `references/process.md` names. The acquirer, the other party to the
agreement, and the users are parties, not processes.

## Inputs

| Work product | Outcomes it serves | Source |
|---|---|---|
| the retirement request | constraints provided, elements disposed | the operation process |
| the customer request | elements disposed, environment restored | the acquirer and the users |
| the maintenance strategy | elements disposed, environment restored | the maintenance process |
| the product release strategy | elements disposed | the maintenance process; the project planning process |
| the product release information | constraints provided, elements disposed | the maintenance process |
| the customer manual: updated during qualification testing | elements disposed | the verification process |
| the system requirements | constraints provided, elements disposed | the system/software requirements definition process |
| the system: installed and in operation | elements disposed, reports available | the transition process |

## Outputs

| Work product | Outcomes it serves | Receiver |
|---|---|---|
| the software retirement plan | constraints provided, elements disposed | the operation process, for the transition to the new product and the parallel operation |
| the disposal constraints | constraints provided | the system/software requirements definition process; the architecture definition process; the design definition process; the implementation process |
| the infrastructure requirements, for the enabling systems of the process | enabling systems available | the infrastructure management process |
| the retirement notification | elements disposed | the users and the customers; the transition process |
| the communication record | environment restored, reports available | the users and the other affected parties |
| the change history | elements disposed, reports available | the configuration management process; the information management process |
| the analysis report: of the long-term impacts | reports available | the knowledge management process |
| the acceptance record: of the completed retirement | reports available | the acquirer; the configuration management process |
