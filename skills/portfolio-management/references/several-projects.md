# Several projects

## Defining and authorizing projects

Outcomes served: projects defined, resources allocated, projects sustained.

| Step | What the agent does |
|---|---|
| Balance | shall calculate and balance the resources and the budgets among the selected projects |
| Interactions | shall identify the interactions and interdependencies between projects that need to be managed or supported, enabling systems and system elements used by more than one project included |
| Enterprise architecture | should understand each project in the context of the enterprise architecture: the interactions and constraints it places on the project |
| Measures | should keep a store of measures and measurements common to all projects, as an element of portfolio management |
