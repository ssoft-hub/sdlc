# Work products of decision management

"This process" as a source or a receiver is a task of decision management passing the work
product to a later one.

## Inputs

| Work product | Outcomes it serves | Source |
|---|---|---|
| the decision making strategy in force | decisions identified | this process |
| the problem record | decisions identified, alternatives evaluated | the quality assurance process; the maintenance process; the acquisition process |
| the project plan | alternatives evaluated, course selected | the project planning process |
| the decision making criteria | alternatives evaluated, course selected | this process, for the criteria in force; the process whose decision it is, for the goals and the constraints of the decision |
| the alternative solution | alternatives evaluated, course selected | the system analysis process; the business or mission analysis process; the architecture definition process; the design definition process |
| the analysis report | decisions identified, alternatives evaluated, course selected | the acquisition process, for supplier selection; the system analysis process, for the values of the criteria and the feasibility of the alternatives; the business or mission analysis process, for the evaluation of the classes of solution; the stakeholder needs and requirements definition process, for the priorities of the needs; the architecture definition process, for the selection of the architecture; the maintenance process, for the trade-offs of maintenance and logistics |
| the product needs assessment, the supplier selection criteria, the supplier proposal response, the assessment report, the audit report, the supplier evaluation report | alternatives evaluated, course selected | the acquisition process, for supplier selection |
| the analysis question: the problem, the goals, the fidelity required | alternatives evaluated | this process |
| the decision: one taken earlier | course selected, rationale recorded | this process |
| the selected solution class: the decision record | course selected, rationale recorded | this process |
| the proposal review record | course selected | the supply process |

## Outputs

| Work product | Outcomes it serves | Receiver |
|---|---|---|
| the decision making strategy | decisions identified | every process whose decisions it covers |
| the change request: a decision that changes the project plan | alternatives evaluated, course selected | the project planning process |
| the decision making criteria | alternatives evaluated, course selected | the stakeholders: the decision maker |
| the alternative solution | alternatives evaluated, course selected | the stakeholders: the decision maker |
| the analysis question | alternatives evaluated | the system analysis process |
| the decision | course selected, rationale recorded | the process whose decision it is; the stakeholders |
| the selected solution class: the decision record | course selected, rationale recorded | the business or mission analysis process |
| the proposal review record | course selected | the supply process; the acquisition process |
