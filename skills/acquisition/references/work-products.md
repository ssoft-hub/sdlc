# Work products of acquisition

"This process" as a source or a receiver is a task of acquisition passing the work product to a
later one.

| Work product | Outcomes it serves | Source |
|---|---|---|
| the business goals | request prepared, supplier selected | the portfolio management process |

| the stakeholder requirements | request prepared, product accepted | the stakeholder needs and requirements definition process |
| the product requirements and the service requirements | request prepared, agreement established | the system/software requirements definition process; the supplier, for the requirements it developed |
| the infrastructure requirements, for an infrastructure element acquired | request prepared | the infrastructure management process |
| the asset specification, for a knowledge asset acquired | request prepared | the knowledge management process |
| the acceptance criteria | request prepared, agreement established, product accepted | the stakeholder needs and requirements definition process |
| the risk management plan | request prepared | the risk management process |
| the acquisition plan | request prepared | the project planning process; the human resource management process, for training from an external supplier |
| the policy | every outcome | the life cycle model management process |
| the supplier selection policy in force | request prepared, supplier selected | this process |
| the supplier selection criteria | request prepared, supplier selected | this process, under the supplier selection policy |
| the request for proposal: the request for supply | request prepared | this process, from the preparation for the acquisition |
| the supplier proposal response | supplier selected | the supplier |
| the assessment report: of the supplier's processes | supplier selected | the supplier |
