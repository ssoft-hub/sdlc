# Work products of measurement

"This process" as a source or a receiver is a task of measurement passing the work product to a
later one. The acquirer is the other party to the agreement; the users of the product are those
whose satisfaction is measured; the external sources are other organizations and the industry, which
benchmarking data come from.

## Inputs

| Work product | Outcomes it serves | Source |
|---|---|---|
| the quality policy | needs defined | the quality management process |
| the customer request | needs defined, measures defined | the acquirer |
| the process description | needs defined, data collected, information provided | the life cycle model management process |
| the field measure | measures defined, data collected, data analysed | the operation process |
| the process measure | data collected, data analysed, information provided | the life cycle model management process |
| the project measure | data collected, data analysed, information provided | this process, for the measure in force |
| the quality measure | data collected, data analysed, information provided | the quality management process |
| the service level measure | data collected, data analysed, information provided | the operation process |
| the process performance data | data collected, data analysed | the quality assurance process; every process whose performance is measured, for the data of its performance |
| the customer satisfaction data | data collected, data analysed | the acquirer; the users of the product; the supply process, for feedback and complaints; the operation process |
| the customer satisfaction survey | data collected, data analysed, information provided | this process, for the survey in force |
| the benchmarking data | data collected, data analysed, information provided | the external sources |
| the asset use data | data collected | the knowledge management process |
| the risk measure | data collected | the risk management process |
| the data and models for analysis | data collected, data analysed | this process, for the measurement data collected and checked |
| the work product distribution register | information provided | the information management process |
| the assessment data | information provided | the quality assurance process |

## Outputs

| Work product | Outcomes it serves | Receiver |
|---|---|---|
| the process description | needs defined, data collected, information provided | the life cycle model management process, for the improvements of the measurement process |
| the field measure | measures defined, data collected, data analysed | every process that decides on the results |
| the process measure | data collected, data analysed, information provided | the life cycle model management process; the quality assurance process |
| the project measure | data collected, data analysed, information provided | the project assessment and control process |
| the quality measure | data collected, data analysed, information provided | the life cycle model management process; the quality assurance process; the verification process; the project assessment and control process, for the management reviews |
| the service level measure | data collected, data analysed, information provided | the operation process; every other process that decides on the results |
| the process performance data | data collected, data analysed | the project planning process; the project assessment and control process; the portfolio management process; the life cycle model management process; the quality management process; the quality assurance process |
| the customer satisfaction data | data collected, data analysed | the life cycle model management process, for the improvement opportunities; every other process that decides on the results |
| the customer satisfaction survey | data collected, data analysed, information provided | every process that decides on the results |
| the benchmarking data | data collected, data analysed, information provided | every process that decides on the results |
| the data and models for analysis | data collected, data analysed | the system analysis process, for the data of its analysis |
| the analysis report | data collected, data analysed, information provided | every process that decides on the results |
| the evaluation report | data collected, data analysed, information provided | every process that decides on the results |
| the process performance report | data collected, data analysed | every process that decides on the results |
| the problem record | information provided | the quality assurance process |
| the infrastructure requirements: for the enabling systems of the process | data collected | the infrastructure management process |
