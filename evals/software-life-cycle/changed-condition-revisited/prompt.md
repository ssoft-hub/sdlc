`fieldnote` is a survey app for field workers. Accepted so far: ADR-1 server-side rendering of the survey pages; ADR-2 sessions kept in server memory; ADR-3 photos uploaded to the server the moment they are taken, which needs the network; and assumption A-1: devices are always online. The customer now requires that workers can fill surveys with no network for up to a day. What does this change? The repository is not available in this session; work from this description.
